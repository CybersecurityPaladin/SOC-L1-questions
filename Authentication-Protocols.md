# The most popular authentication protocols

🖥️ <ins>**Windows / Enterprise (Active Directory)**</ins>  
**1. Kerberos** - Ticket-based authentication  
**2. NTLM** - Challenge-response authentication  
**3. LDAP** - Directory service queries  

🌐 <ins>**Web Applications**</ins>  
**4. OAuth2** - Delegated authorization framework  
**5. OpenID Connect** - Identity authentication layer  
**6. JWT** - Signed authentication tokens  
**7. Session Cookies** - Session-based authentication  

☁️ <ins>**Cloud Platforms (AWS / Azure / GCP)**</ins>  
**8. IAM Tokens** - Temporary access credentials  
**9. STS** - Short-term access tokens  

🗄️ <ins>**Network / Infrastructure**</ins>  
**10. RADIUS** - Network access authentication  
**11. TACACS+** - Device access control protocol  
**12. 802.1X** - Port-based authentication  

🐧 <ins>**Linux / SSH**</ins>  
**13. SSH Keys** - Key-based authentication  
**14. Password** - User password authentication  
**15. PAM** - Authentication management framework
